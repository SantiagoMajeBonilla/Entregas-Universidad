# Clínica Vitalis - Versión HTML, CSS y Bootstrap

Primera versión de la página de Clínica Vitalis, construida con HTML, CSS y Bootstrap 5 (antes de la migración a Angular).

## Archivos
- `index.html`: estructura de la página (encabezado, barra de navegación, carrusel, médicos, formulario de registro, productos y footer).
- `styles.css`: hoja de estilos personalizada (variables de color, tipografías, estilos de cada sección).
- `script.js`: lógica del negocio en JavaScript (mostrar descripción de especialidad al hacer clic, validaciones del formulario de registro al perder el foco y al dar clic en "Registrar").

## Cómo ejecutar
Simplemente abre `index.html` en tu navegador (doble clic, o clic derecho → "Abrir con" → tu navegador). No requiere instalación ni servidor.
